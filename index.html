نظام التشغيل (OS)

Concept 1

نظام التشغيل هو البرنامج الأساسي الذي يدير موارد الحاسوب. تتمثل مسؤولياته الأساسية في توفير واجهة للمستخدم، وإدارة الذاكرة، والتحكم في الأجهزة الملحقة.

An Operating System (OS) manages computer hardware. Its primary responsibilities include user interface, memory management, and device control.

النواقل (System Buses)

Concept 2

تنقسم النواقل إلى ثلاثة أنواع: ناقل البيانات لنقل المعلومات، ناقل العناوين لتحديد مكان الذاكرة، وناقل التحكم لإرسال إشارات الأوامر بين القطع.

Buses are divided into three types: Data Bus for information, Address Bus for memory locations, and Control Bus for command signals.

ترقية المكونات (Upgrading)

Concept 3

ترقية الهاردوير مثل زيادة حجم الرام أو استخدام قرص SSD يحسن من سرعة النظام وكفاءته بشكل كبير ويقلل من أوقات التحميل.

Hardware upgrading, like increasing RAM or using an SSD, highly improves system speed, efficiency, and reduces loading times.

الحماية الكهربائية (Safety)

Concept 4

أثناء الصيانة، يجب على الفني استخدام سوار المعصم المضاد للكهرباء الساكنة لمنع تلف القطع الإلكترونية الحساسة.

During maintenance, technicians must use an anti-static wrist strap to prevent damage to sensitive electronic components.
